## Variables de Entorno

### Backend
- `PORT`: Puerto del servidor (default: 3000)
- `NODE_ENV`: Entorno de ejecución (development/production)
- `HUBSPOT_API_KEY`: API Key de HubSpot
- `HUBSPOT_PORTAL_ID`: ID del portal de HubSpot
- `ALLOWED_ORIGINS`: Orígenes permitidos para CORS (separados por comas)
- `RATE_LIMIT_WINDOW_MS`: Ventana de tiempo para rate limiting en ms
- `RATE_LIMIT_MAX`: Número máximo de solicitudes por ventana

### Frontend
- `PUBLIC_API_URL`: URL del backend
- `PUBLIC_SITE_URL`: URL del sitio
- `PUBLIC_HUBSPOT_PORTAL_ID`: ID del portal de HubSpot
